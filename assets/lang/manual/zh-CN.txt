=== 从这里开始（Start here）
try: 开始导览（Take the tour）
谱面编辑器可用于制作太鼓谱面。保存为 .osu 的谱面可在 osu!stable 中正常游玩；保存为 .tko 时会叠加 taiko.rs 自带的动画，且不会修改原来的 .osu 文件。

# 从歌曲创建谱面
- 在主菜单选择 EDITOR，或将 mp3 / ogg / wav / flac 文件拖到游戏窗口。
- 详情页可填写艺术家、曲名、谱师、难度名称和背景图片。非英文名称也应填写罗马字版本（osu! 规则）。
- 节奏页会自动检测 BPM 和首拍。请试听确认（参见“歌曲节奏校准”）。
- 点击 Create 后，谱面文件夹会创建在 Songs 中，并在编辑器内打开。

# 歌曲设置
File > Song setup 可随时修改名称和设置：艺术家与曲名（各自的罗马字版本）、谱师、难度名称、出处、标签，以及 HP 消耗、准确度（OD）和基础 SV。
- 点击输入框并输入内容；按 Enter 或 Tab 确认。按 Tab 可前往下一个输入框。数值也可用 - 和 + 调整（Shift 加大步进，Alt 微调）。
- 调整 OD 时，窗口会显示判定时间范围和星级。
- 基础 SV 决定 SV 为 1.0x 时音符的滚动速度。修改基础 SV 不会改变任何滚动音符的时长。
- 每次修改都可单独撤销；按 Ctrl+S 将修改保存到谱面。

# 界面
- 模式：F1 Compose（谱面音符）、F2 Gimmicks（Stable 机关）、F3 Timing（BPM 与滑条速度）、F4 Effects（特效片段、关键帧和节点，仅限 .tko）。
- 时间轴从左向右延伸；白线是播放指针。Alt+滚轮缩放，中键拖动视图。
- 预览会显示播放指针所在位置的实际游戏画面。
- 将鼠标悬停在项目上可查看提示。每条命令都在菜单中，并标有对应按键。

> 请经常保存：Ctrl+S。首次保存时会保留原文件的 .bak 备份。Ctrl+Z 撤销，Ctrl+L 恢复到上次保存状态（需按两次）。

File > Open song folder 可打开当前谱面的文件夹。将其他难度文件（.osu 或 .tko）拖入后，歌曲列表会在一秒内更新，无需重启。

=== 歌曲节奏校准（Timing a song）
try: 打开节奏窗口（Open the timing window，F6）
谱面的质量取决于节奏校准：每个音符都会吸附到由红线构成的网格上。红线标记 BPM 和首拍时刻。请先校准节奏。

# 使用新建谱面向导
- Detect（检测）：游戏会分析整首歌曲并给出 BPM 和偏移。如果歌曲中有变速，也会提示你。
- Tap（跟拍）：按小节节拍按 T，BPM 会根据你的点按计算。
- Metronome（节拍器，M）会在每拍发声，并在每小节首拍时加重。Loop 8 bars（循环 8 小节，L）会重复播放一段，方便试听。
- Beat at the playhead（将播放指针设为首拍，B）：播放到清晰的鼓点处，暂停，然后按 B 将此处设为一拍。
- Meter（拍号）：4/4 或 3/4 决定每小节从哪里开始。

# 试听校准
- 在连续 4 小节的拍点上放置音符，将 Speed 设为 50% 后点击 Play。如果音符始终同样偏早或偏晚，请调整偏移。如果歌曲越往后偏差越大，说明 BPM 略有误差。
- BPM 和偏移旁有小号的 +/- 按钮，可进行精细调整（最低步进为 0.01 BPM 和 1 ms）。
- 点击 BPM 或偏移输入数值（逗号也可作为小数点；按 Enter 或点击其他位置确认，按 Esc 取消）。偏移可以是负数，拍点网格以歌曲起点为基准绘制。
- 对照网格线和波形峰值：峰值应落在网格线上。
- 波形颜色代表声音类型：红色为低频（底鼓，常对应咚），蓝色为高频（军鼓或踩镲，常对应咔）。编辑器中也会在音符下方显示波形（View > Waveform 开 / 关）。

# 编辑器中的节奏校准
- F3 Timing：选中红线即可修改 BPM、偏移和拍号。F6 可查看所有红线。
- 面板中的 Position 区块用于移动红线：输入时间（可以是负数，谱面的首拍可以早于 0），按 1 ms 或 10 ms 微调，也可按小节或单拍移动。每次操作都可单独撤销，音符位置保持不变。Tempo 区块可调整 BPM（- 和 +，步进为 1 或 0.01，也可乘以 2 或除以 2）及拍号。
- 从第一条红线往前到歌曲开头也会绘制拍点网格，放置在那里的音符也会吸附到网格。
- 按 T（或打开 Timing 面板中的 Metronome 开关），歌曲播放时节拍器会逐拍发声，并在每小节首拍时加重。节拍器会跟随每条红线、BPM 和拍号变化以及播放速度。
- Ctrl+P 在播放指针处添加红线（更改 BPM 并重置网格）。Ctrl+I 删除播放指针处的红线。
- 打开红线上的 Kiai 开关可标记激昂段落。总览栏会以橙色显示。

> 有多种速度的歌曲需要在每个变速处添加红线。按上述方法试听并校准后半段，再添加对应红线。

=== 音符与音效（Notes and sounds）
# 放置音符
- 工具：1 Select（选择）、2 Note（音符）、3 Drumroll（连打）、4 Denden（连打音符）。使用 Note 时，点击音轨即可在网格位置放置音符；右键删除音符（选中音符时删除整个选区）；拖动可移动音符（Shift 可忽略网格）。
- Snap 设置每拍的细分：使用 Ctrl+滚轮或 Shift+1 至 9。按 Left / Right 可移动一个吸附步进。
- 点击传输栏中的 Snap 可打开吸附预设。All 是完整列表，也是默认值。New preset 可勾选所需步进（例如 1/1、1/2、1/4、1/8，或 1/3、1/6、1/12），并以这些步进生成预设名称；Delete 会删除当前预设。启用预设后，Ctrl+滚轮只会切换其中的步进，吸附也会跳到预设内最近的步进。点击列表中的步进或按 Shift+1 至 9，仍可选取任意单个步进。按 Esc 或点击列表外部可关闭列表。预设会保存在设置中。
- Speed（Ctrl+上 / 下方向键）可减慢音乐，方便跟着节奏放置音符。

# 颜色与大小
- 按 W 可切换为咔（再次按下则切回咚），按 E 可放置大音符。这些设置会应用到当前选区，或之后放置的音符。
- 按 Q 可切换咚和咔。按 J / K 微调位置，Ctrl+D 复制，Ctrl+G 反转。

# 选择与复制
- 在空白音轨上拖动可框选（使用任意工具时按住 Ctrl 拖动）。Ctrl+A 全选。
- 取消选择：按 Esc、使用 Select 工具点击空白音轨，或按 Ctrl+Shift+A。按住 Ctrl 并点击音符可将其加入选区；如果音符已选中，则会将其移出选区。使用 Note、Drumroll 或 Denden 时，点击空白音轨会放置音符，因此请按 Esc 取消选择。
- 拖动连打或 Denden 右端的浅色条可调整长度。它会吸附到网格（按住 Shift 可精确到毫秒），长度至少为一个吸附步进，并且不会延伸到下一个音符之后。每次拖动都可单独撤销。
- Ctrl+X / C / V 可在播放指针处剪切、复制和粘贴。

# 书签与歌曲
- Ctrl+B 添加书签，Ctrl+左 / 右方向键可在书签之间跳转。书签保存在 .osu 文件中。
- 按 Z / V 跳到第一个 / 最后一个音符。图表下方的横条代表整首歌曲，点击即可跳转。

=== SV 与 SV 工具（SV and the SV tool）
try: 打开节奏窗口（Open the timing window，F6）
# SV 是什么
绿色线条设置滑条速度（SV）：决定音符滚动速度和滑条长度。x1.00 为正常速度，x2.00 为两倍速度。音符的时间不变，变化的是它们在屏幕上的间距。谱师会用 SV 让高潮段落更有冲击力，让铺垫听起来逐渐加速，或让过渡段放慢。

# 图表（F3）
- 双击空白处可添加绿色线条，拖动控制点可调整，右键删除。拖动控制点时会吸附到网格；按住 Shift 可精确到毫秒，按住 Ctrl 可保持时间不变、只修改数值。
- 音符上方的条带中，红线（BPM）在上方，绿线（SV）在下方。点击可选中线条，Shift+点击可添加到选区；在空白条带上拖动可框选多条线。拖动选中线条可沿网格一起移动，按住 Shift 可精确到毫秒。
- 跟随音符（红线的 Position 标题旁，也可在 Timing 菜单中找到）：启用后，更改红线时间或 BPM 时，该段的音符和绿色线条也会一起移动，因此它们与节拍的相对位置不变，效果类似 osu!stable 的 “Move already placed notes when changing the offset/BPM”。
- Timing > Snap notes to the grid 可将稍微偏离的音符重新吸附到网格，类似 Mapping Tools 中的 Map Cleaner：勾选要细分的拍点，设置音符允许移动的距离（偏差更大时会保留，可能是你有意这样放置），选择当前选区或整张谱面，并决定是否同时吸附连打末端和独立绿线。音符上的绿线会跟随音符，SV 模式中的绿线会保留原位，不会有音符重叠。点击 Snap 前会先预览改动；按一次 Ctrl+Z 即可撤销。
- 拖动框选多条线：可以一起移动，也可以缩放（按住 Alt 可将线条加入选区，而不是缩放）。
- 已形成曲线的线条会以细线显示，并标注类似 sin x1.20 > x2.00 的数值。点击曲线可编辑；可拖动两端的圆形控制点。
- SV | Volume 开关会将所有拖动操作切换为音量编辑。用 Brush（画笔）在两点之间拖动即可绘制曲线；如果终点靠近现有线条，会自动吸附并与其连接（按住 Alt 可取消吸附）。

# SV 工具
SV 工具会沿曲线自动生成多条绿色线。在 Timing 面板中打开，或前往 F6 > SV tool。
- 选择两条绿色线（点击第一条，再按住 Shift 点击另一条），从 Presets 中选取预设，设置起始和结束速度，然后点击 Apply。工具会先显示待生成线条的预览；点击 Apply 前不会修改内容，按 Ctrl+Z 可撤销。
- 预设：ramp（渐变）、geometric ramp（几何渐变，速度均匀提升）、multiply（倍增）、每个音符一条线、ease in（缓入）、ease out（缓出）、S-curve（S 曲线）、正弦曲线。
- 线条的生成位置：现有线条、拍点网格或音符。

# 配方
- 渐慢进入高潮：在渐慢段落的开头和结尾放置绿线，选择 Ease out，从 x1.00 渐变到 x0.60。
- 逐渐加速：在 2 小节范围内放置两条线，选择 Geometric ramp，从 x0.80 渐变到 x2.00。
- 音量渐弱：切换到 Volume，在段落最后几小节内将音量从 100 渐降到 30。
- 每个音符使用独立速度：选择 Curved line on every note。

> 除非启用了 Ignore BPM，否则 SV 会按滚动速度（SV x BPM）进行比较，因此改变 BPM 不会让曲线突然跳变。

=== Stable 机关（Stable gimmicks）
F2 Gimmicks 可创建 osu!stable 谱师常用的结构：假滑条、反小节线墙和生成式 SV。选择工具，在面板中设置数值，然后应用到播放指针处或当前选区。Preview 会预览效果；选择 Keep 保存，选择 Cancel 放弃。每次应用都可单独撤销。

这些机关可用于普通 .osu 谱面，在 osu!stable 中也会以相同方式游玩。此处的内容都不依赖客户端自带动画。

=== 特效片段（Effect clips）
try: 在这张谱面上添加示例（Put an example on this map）
F4 Effects 会打开 Clips。这是让 .tko 谱面改变游玩区域效果的简单方式。特效在时间轴下方各行显示为方块，起止位置决定生效范围，并始终与音乐同步。

# 创建特效片段
- 工具架包含以下分页：Playfield（游玩区域脉冲、旋转、缩放、震动）、Lane（轨道形状）、Notes（音符）以及 Look（闪光、颜色、回声、半透明、黑屏）和 Text & pictures（文字与图片）。
- Copies：最多可在游玩区域后方添加四个副本，每个副本都可用自己的片段移动（显示状态、x、y、旋转、大小、轨道透明度）。在片段设置中指定 copy 1-4。可试试 Mirror twin、Triple lane、Shadow clones、Spinning ghost。只有原始游玩区域参与游玩。
- Cut in pieces 会将画面切成 2-12 个竖直碎片；Pieces up / down 会让碎片交错上下移动，Pieces apart 会从中心向外散开。可试试 Broken lane、Shatter on the beat、Split open。
- Blackout 和 Fade to black 会让屏幕变黑（轨道上的文字仍会显示）；Ghost playfield 会让游玩区域变淡；Only the notes 会在黑屏上只显示音符和太鼓。即使音符不可见，也仍然可以击打。
- 点击特效将其选中，然后在某一行从生效位置拖到结束位置。点击一行可放置一小节。Over the kiai here 和 Over the notes selected 可将片段覆盖在当前激昂段或已选音符上。按 Shift 可继续保持选中；按 Esc 可取消选中。
- 片段可以从歌曲播放前开始：例如提前两秒显示首个音符，或从谱面的 AudioLeadIn 开始。这样可让游玩区域从第一帧起就处于指定状态（缩小、旋转或变暗）。
- 拖动片段可移动（也可移至另一行）；拖动两端可缩短或延长（短片段的边缘也可拖动）；右键删除。片段不会互相重叠：如果将片段放到另一片段上方，它会移至最近的空闲行，片段末端也不会超过下一个片段。
- 在空白行上拖动可框选多个片段；按住 Shift 或 Ctrl 点击可添加或移除片段。已选片段可一起移动，Ctrl+D 可在它们后方复制，Delete 可删除。
- 操作方式与 Ableton 相同：按住 Ctrl 拖动片段（或按住 Ctrl+Shift 拖动）可复制该片段；如果拖动的是已选片段，则会复制全部选中内容。Ctrl+C 或 Ctrl+X 后，片段仍保持选中；按 Ctrl+V 会将其放到播放指针处，并把播放指针移到片段末尾，因此连续粘贴会依次排列。也可粘贴到其他谱面。Ctrl+A 选中所有片段。
- 底部始终保留一行空位。行数过多时，可在这些行上按住 Shift 滚动滚轮（或滚动行旁的滚动条）来滚动列表。在各行上直接滚动滚轮可像音符区一样浏览歌曲；拖动或调整片段至视图边缘之外时，视图会跟随滚动。

# 修改特效片段
- 点击片段后，工具架会显示它的设置。点击它所影响的内容，即可打开按列排列的菜单：Playfield（缩放、旋转、震动等）、Look、Echoes & cuts、Lane（螺旋、锯齿、循环等）、Notes（移动、大小、隐藏、旋涡、拉伸、着色）和 Copies。用 < 和 > 切换。切换项目时，数值会保持当前大小。
- 生效时机：持续生效、每隔几拍生效、击中音符时生效（所有音符、咚、咔、大音符），或在击中、失误时生效。
- Notes 特效可以移动所有音符，也可以只移动某个组。点击 all notes 可在组之间切换。要指定音符，先在时间轴上选中它们，再点击 only the selected notes；这些音符会组成独立的一组，并从原来的组移除（每个音符只能属于一个组）。+ selected 和 - selected 可添加或移除音符；select its notes 会选中该组音符。特效仅在片段生效期间、且音符位于屏幕上时作用于它们。因此若要让音符从出现到击中都保持隐藏，请在它们出现前开始片段，并在最后一个音符击中后结束片段。
- Amount 是作用强度：点击并输入数值（按 Enter 或点击其他位置确认），或使用 - 和 + 调整（Shift x10，Alt x0.1）。
- 持续生效的片段会按照设定的拍数淡入淡出。循环片段可以执行 kick（跳起后落回）、swing（左右摆动）或 step（每次逐步增加）效果，并按照设定拍数循环。
- Keep after：片段结束时保留达到的效果（例如旋转到一半后停止，就保持在该位置）。
- Fit to kiai 和 Fit to selection 可将片段延展至对应的激昂段或选区。

# 文字与图片
- 工具架中的 Text、Fly-in text 和 Pulsing text 可使用游戏字体在屏幕上显示文字。点击片段设置中的文字并输入；首个按键会替换原文字，Ctrl+Backspace 删除一个词。
- Picture 和 Logo on the beat 可显示谱面文件夹中的图片：将 .png 或 .jpg 拖到编辑器窗口（图片会复制到文件夹并应用到选中的图片片段），也可自行放入谱面文件夹。按 < 和 > 可切换；点击图片名称可查看全部图片及其预览。图片会随谱面保存在 .rsz 中。
- 选中图片后，拖动预览即可调整位置：Shift 旋转，Ctrl 调整大小。也可输入 x、y、大小、旋转角度和不透明度（0 为不可见，1 为完全不透明）。设置移动效果时，若结束位置的不透明度不同，图片会淡入或淡出。
- moves：图片会从起始姿态平滑移动到结束时设置的姿态。Edit start pose 和 edit end pose 用于选择要修改的起始或结束参数；预览会同时标记两个姿态，并显示虚线轨迹。
- spin 会使图片持续旋转，每拍转动指定角度（每拍 360 度即完整旋转一圈，负数表示反向旋转）。
- behind the notes 会将图片放在轨道下方；fades 会淡入淡出；pulses 会在拍点、音符或击打时放大图片（数值以百分比表示）。

# 实时录制
- 歌曲播放时，按 1 到 9 可录制工具架当前分页中的特效：在特效开始位置按一次，在结束位置再按一次。按 Esc 可取消当前录制。

# 手动移动游玩区域
- 拖动预览可移动游玩区域。按住 Shift 拖动可旋转，按住 Ctrl 拖动可缩放（向上放大，向下缩小）。
- 每次拖动都会在播放指针处留下关键帧。移动播放指针后再次拖动，游玩区域就会在这些关键帧之间平滑移动。Ctrl+Z 可撤销整次拖动。
- 关键帧在行上方的 Motion 条带中显示为菱形。点击菱形可跳转到该关键帧，右键可删除。

# 配方
- 激昂段每两拍触发一次：使用 Every 2nd beat，并在播放指针位于激昂段时放置。
- 每个大音符触发震动：使用 Big note slam。
- 在歌曲最后一段副歌隐藏音符：选中对应音符，点击 Hide the notes。
- 每小节转四分之一圈并保持：使用 Quarter turns。

片段会与彼此、关键帧和节点共同生效。页面标签分隔线之后的 Keyframes 和 Nodes 可用于实现片段暂不支持的效果。

> 此处的内容只影响画面，不会改变判定、分数或 pp。

=== 音符路径
try: 在此谱面添加示例（Put an example on this map）
F4 Effects（特效）> Motion（动作）页面（仅适用于 .tko 谱面）：选中的音符会沿你绘制的路径飞向鼓面，而不是沿轨道滚动，并在击打时准确抵达。

# 为音符绘制路径
- 按 1 选择 Select 工具（仍停留在此页面），然后点击时间轴上的音符，或拖动框选多个音符。在 Effects 页面，点击时间轴只会选中音符，不会放置音符。
- 选择音符的起点：上方、下方、鼓后、角落，或弧线、下落、之字形、螺旋、环形路径。选中的音符会组成一个新组，并同时沿该路径飞行。（Give the picked notes a path 也能完成相同操作，默认从上方开始。）
- Straight lane 会让选中音符沿普通直线轨道移动；clips 则会将轨道弯成之字形、螺旋或其他形状。它们离鼓面的距离和移动速度与普通轨道相同。使用 When 可让音符在一拍内移上该路径，再回到弯曲轨道。
- 页面只会调整当前选中的音符：点击 Moving 下方的组即可重新选中该组的音符。各组会排列在同一行。组数过多时，可用箭头或在其上滚动鼠标滚轮翻页；数字会显示两侧隐藏的组数。
- 时间轴上音符下方会显示一个带组名的横条，标明当前页面正在调整哪些音符。
- 在预览中编辑路径：拖动节点可移动，双击可添加，右键可删除。白色节点是音符进入路径的位置，路径始终以鼓面为终点。

# 音符如何沿路径移动
- 音符沿路径前进的距离与沿轨道前进的距离相同：它会在原本到达轨道末端时从路径起点进入。滑条速度仍然生效，因此慢速音符沿路径移动也较慢。
- Pace 可调整沿路径移动的节奏：Stop half way 会让音符在中途停下，Rush the end 会让音符快速冲向终点，Soft landing 会让音符在鼓面前减速，Back up 会让音符后退一次。

# When（时段）
- Always：整首歌曲都沿路径移动。
- Onto the path here 和 Back to the lane here 会让音符从播放指针处开始，在一拍内平滑移上路径或回到轨道。配合使用即可只在副歌期间改变路径。
- Show the path 会为玩家淡淡地显示路径，让他们看清音符将从哪里出现。

# 更多音符，共用同一动作
- 使用 Copy motion，选中其他音符，再使用 Paste motion，即可让这些音符共用相同路径、速度和关键帧。
- Select them 会在时间轴上重新选中某个组内的音符。一个音符只能属于一个组；为它设置新路径后，它会离开原来的组。

# 击打前的动作
- Before the hit 页面可为选中音符设置临近击打时的独立动作，无论音符当时位于何处。可选淡入、提前消失、弹出、下落、从下方升起、跳起、旋入、闪烁、抖动或在击打时压扁。
- 也可在曲线上自行设置关键帧：选择要调整的属性（淡入、大小、上下、左右、旋转、隐藏、宽度、高度、色调），点击添加关键帧，拖动它来移动，右键删除。曲线左侧表示击打前 4 拍，亮线表示击打时刻。关键帧按 1/8 拍吸附；按住 Shift 可自由放置。
- 该功能可与路径及 Keyframes 页面配合使用：移动和旋转量会相加，大小和淡入程度会相乘。

# 滚动（mania SV）
- Scroll 页面可为整首歌曲的轨道设置统一速度，类似 osu!mania 的 SV：1x 按谱面原速播放，2x 快一倍，0x 会将所有音符定在原处，-1x 则反向移动。绿色节拍线保持原样，此设置会叠加在其上。例如，2x 绿色节拍线配合 0.5x 滚动速度，实际播放速度为 1x。
- 选择速度后，该速度会从播放指针持续到下一个关键帧。Slower 和 Faster 可微调速度；Glide to the next key 会平滑过渡到下一种速度，而不是突然跳变。
- 可从播放指针处添加动作：Freeze a beat（停住一拍）、Back up a beat（后退一拍）、Lurch on each beat（每拍突进一次，持续一小节）、Jump a beat ahead（向前跳一拍）。每种动作结束后都会恢复原速度。
- 时间轴下方的曲线显示滚动速度。点击可添加关键帧，拖动可移动，右键可删除。
- Slide the drum along the lane 可在播放指针起的一拍内，将判定目标移动到 Home、A quarter in、Half way 或 Far。音符会在目标所在位置与其相遇。这是 Move the drum 效果，因此也可以用 Keyframes 页面和 clips 移动判定目标。
- 无论滚动速度如何变化，每个音符都会在应被击打的时刻准确抵达鼓面。

# 假音符
- Fakes 页面可将选中的 don 和 kat 音符设为假音符，也可还原。假音符外观和移动方式与普通音符相同，但不会触发击打、分数或连击，也不会发声，并会在鼓面处消失。
- Add fake copies of the picked notes 会在选中音符前后半拍、1/4 拍或一拍处添加假音符副本。副本与原音符共用分组，因此路径和动作也相同。
- 时间轴轨道底部有假音符专用行（FAKES），以带 F 的空心音符显示，不会遮住普通音符。谱面包含假音符后才会出现此行；可在这里创建第一个假音符。使用 Note 工具点击此行即可放置假音符，也可叠放；使用 Select 工具选中并拖动假音符。点击叠放位置会选中其中一个假音符，再次点击会选中下一个（叠放标记例如 2/3）。假音符可与普通音符处于同一毫秒，多个假音符也可同时刻叠放（例如显示 x3）；但普通音符每毫秒只能有一个。假音符可以像普通音符一样选中、移动、复制和删除；框选也会选中范围内的轨道。假音符默认与同毫秒的普通音符共用分组；若要让它独立移动，可选中它（也可从叠放位置中选取）并为其设置独立路径、动作或分组。这样即使同一毫秒还有其他音符或假音符，它也会单独移动。

# 显示为
- Show as 页面可改变选中音符的外观：全部显示为 don、全部显示为 kat、互换两者，或统一缩小、放大、互换大小。
- The truth shows 会在击打前最多两拍内逐渐还原音符的真实外观，过渡持续 1/4 拍。若某种颜色直到击打时才出现，玩家无法提前判断，只能记住它；Upload 会对此发出警告。
- 音符的击打类型、分数和声音都不受外观变化影响。假音符也会随所在分组改变外观；鼓面连打和鼓面膨胀音符不会改变外观。
- 玩家可在 Settings > Gameplay > Show true notes 中关闭所有外观伪装。开启后，你自己的预览中也会显示真实外观。
- Over effects 位于同一页面，可让选中音符显示在所有特效之上：黑屏、闪光或故障效果都不会遮住它们，作用于所有音符的特效也会避开它们。音符仍会随游玩区域旋转和缩放；作用于所属分组的特效仍会移动它们。时间轴上的这类音符会带白点标记。

- 点击下方的 Put an example on this map 会在谱面第一段 kiai 中展示以上效果，每项持续四拍：路径、加入假音符的弹出动作、鼓移动时的冻结效果，以及互换颜色。每项操作都可单独使用 Ctrl+Z 撤销。

> 路径、动作、滚动、假音符和外观伪装都只影响画面：音符的击打时机、分数和 pp 均保持不变。鼓面连打和鼓面膨胀音符仍沿轨道移动。玩家可在 Settings > Gameplay > Reduce map effects 中降低闪光、故障效果和镜头移动。

=== 关键帧
F4 Effects > Keyframes 页面可随时间为游玩区域（通过各标签调整移动、外观和克隆属性）及音符分组制作动画。仅适用于 .tko 谱面。

# 使用方法
- 选择目标：游玩区域或一个音符分组。然后选择一个属性，例如 Zoom。
- 时间轴下方的曲线会显示该属性的关键帧：点击可添加，拖动可移动，右键可删除。拖动时，数值会吸附到整数步进（Shift：自由移动）。也可先移动播放指针，再使用 Key here。点击选中关键帧的 Value 或 At ms 可精确输入数值；按 - 或 + 可逐步调整。Ctrl+C / Ctrl+V 可将选中的关键帧（未选中时复制整条轨道）复制到播放指针处，也适用于其他属性。
- 两个关键帧之间的数值会平滑过渡；Ease 可设置过渡方式。
- 分组：在 Compose 中选择音符并新建分组，然后为分组设置独立动作（位移、缩放、不透明度、隐藏、旋转）。

关键帧固定在时间线上。若要让效果响应节拍、连击数或 Miss，请使用下一章的 Nodes。两者可以叠加：节点的动作会加到属性自身的关键帧效果上。

> 此处的效果都只影响画面，不会改变判定、分数或 pp。

=== 节点
try: 打开 Nodes 页面（Open the Nodes page）
节点是一种简单的视觉程序。你无需手动制作动画，只要指定 WHEN（何时触发）和 WHAT（执行什么动作），再将两者连起来，例如 Every beat -> Pulse（每拍脉冲缩放）。节点位于 F4 Effects > Nodes 页面（适用于 .tko 谱面；打开 .osu 谱面时会询问是否转换为 .tko）。

# 按标题颜色区分节点类型
- Events（事件）：时间点。Start、At time、Every beat、Kiai starts / ends、Note arrives、Hit、Miss、Combo reaches、At mark。
- Triggers（触发器）：改变事件触发时机。Delay、Every Nth、Only first、Gate、Either。
- Values and math（数值与运算）：随时间变化的数值。Combo、Accuracy、In kiai、Beat phase、Wave、Random、Fade out、Progress、Span progress、Add、Scale、Blend…
- Actions（动作）：唯一会改变画面的节点。Pulse、Tween、Shake、Drive、Play clip。

# 两种连线
- 橙色：事件，表示此刻发生某事。
- 青色：数值，表示可随时读取的数值。
连线只能连接相同颜色的节点。节点左侧是输入，右侧是输出。拖动节点圆点到另一个圆点即可连线；右键节点可删除。

# 第一个特效
- 1. 按 F4 打开 Nodes 页面。在右侧点击 + Every beat，即可添加一个节点。
- 2. 点击 + Pulse（Actions），添加第二个节点。
- 3. 从 Every beat 右侧的圆点拖到 Pulse 的 on 圆点。连线为橙色。
- 4. 点击 Pulse 节点。在右侧列表中将目标设为 Zoom。设置 amount 为 0.06，ms 为 260（点击数值即可输入）。
- 5. 按 Space。游玩区域会随每一拍起伏。

# 各动作的效果
- Pulse：每次触发时按 amount 推动目标，然后在 ms 时长内逐渐复原。
- Tween：每次触发时将目标移向设定数值，然后再移回来。
- Drive：持续将目标保持在连入的数值乘以 gain 的结果。适用于跟随数值变化的效果，例如连击数、kiai 或波形。
- Shake：让整个游玩区域朝随机方向抖动，然后逐渐停止。无需指定目标。
- Play clip：播放一小段预先制作好的关键帧动画。
- 动作的 scale 输入为可选项：传入一个数值，在触发时读取并与效果相乘。留空时按 1 处理。

# 效果示例
- 每四拍触发一次：Every beat -> Every Nth（n = 4）-> Pulse。
- 只在 kiai 中闪光：Every beat -> Gate；将 In kiai 连到 Gate 的 open 输入；再将 Gate 连到 Pulse（target 设为 Flash）。
- 每次收尾音都比上次更强：Note arrives（type 3）-> Progress；将触发器和 Progress 同时连到 Pulse 的 on 和 scale 输入。
- 缩放跟随连击数：Combo -> Scale（times 0.002）-> Drive（target 设为 Zoom）。
- 在两个位置之间旋转：按 M 添加标记。Span progress（from 1 to 2）-> Drive（gain 360，target 设为 Rotation）。
- 持续摆动：Wave（beats 4，amount 10）-> Drive（target 设为 X）。

# 没有效果？
- 节点上出现红色 ! 表示它暂时无法工作。将鼠标悬停其上即可查看缺少什么。
- 动作节点若没有目标，会用红色显示 no target。请在右侧选择目标。
- 事件必须连到动作节点的第一个输入端（on / flip / value）。
- 事件会在歌曲播放时触发。跳转播放指针后，请从稍早的位置开始播放。
- Kiai 节点需要在节奏线中启用 kiai。At mark、Between 和 Span 需要先按 M 添加标记；标记按时间顺序从 1 开始计数。
- 数值太小会难以看见。可尝试较大的数值：Zoom 设为 0.1 到 0.3，Shake 设为 10 或更高。
- 下一章的 recipes 是可打开查看的有效示例。

=== 上传与分享
File > Upload 会将已保存的谱面发送到 taiko.rs。

# 上传步骤
- 首先确认：已登录、谱面已保存、谱面属于太鼓模式且至少有 10 个音符、艺术家 / 曲名 / 谱师均已填写、歌曲文件位于谱面文件夹中，而且这是你自己的谱面（没有 osu! BeatmapSetID）。
- Send 会打包谱面文件夹（所有音符数量达标的太鼓难度、歌曲、图片和 storyboard），然后上传。
- 谱面组会立即以 CUSTOM 状态公开：它会显示在网站的 CUSTOM 标签页，任何人都可以下载。游玩这些谱面不会获得 pp。
- 管理员或已获授权的推荐人可以批准谱面。获得 APPROVED CUSTOM 状态后，游玩可获得 pp。

# 更新谱面组
谱面组编号保存在谱面文件夹中，因此再次发送会更新同一谱面组（按钮会显示 Update the set）。已通过审核的难度会保留状态；修改过的难度需要再次审核。

# 游戏中的显示
自定义谱面在选曲界面拥有独立标题（taiko.rs custom、Custom、approved），也可使用 status:custom 搜索。网站下载的谱面也会带有相应标记。

> 每个账号最多创建 30 个谱面组，每组上限 40 MB，每 30 秒可发送一次。

=== 快捷键
# 游玩与移动
- Space 或 C：播放或暂停。X：从头开始播放（与 stable 中相同）。
- F5：测试游玩。无论谱面是否已保存，都会从当前播放指针位置在正式游戏中游玩；Shift+F5 从头开始，并启用 No Fail，且不会保存成绩。退出游玩或谱面结束后会返回此处。
- 在测试游玩中按 Tab（与 osu! 相同）可切换自动游玩；再次按 Tab 可恢复手动游玩。
- Z / V：跳到第一个 / 最后一个音符。左 / 右：按吸附步进移动。上 / 下：切换上一条 / 下一条节奏线。
- 滚轮：定位播放位置。Ctrl+滚轮：切换吸附步进。Alt+滚轮：在时间轴上缩放，在其他位置调节音量。按住鼠标中键拖动：平移视图（View > Left drag pans 可让鼠标左键也能平移空白时间轴；启用后使用 Ctrl+拖动框选）。
- Ctrl+上 / 下：调节播放速度（配合 Shift 时每次变化 5%）。

# 音符编辑
- 1 2 3 4：切换工具。W E：kat、大音符。Q：翻转。J K：微调位置。Ctrl+D：克隆。Ctrl+G：反转。
- Ctrl+Z / Y：撤销 / 重做。Ctrl+X / C / V：剪切 / 复制 / 粘贴。Ctrl+A：全选。Ctrl+Shift+A 或 Esc：取消选择。Delete：删除。

# 节奏与其他操作
- Ctrl+P：添加红线。Ctrl+Shift+P：添加绿线。Ctrl+I：删除节奏线。F6：打开节奏设置窗口。T：节拍器。
- Ctrl+B：添加书签。Ctrl+左 / 右：跳到上一个 / 下一个书签。
- M：在播放指针位置添加特效标记（.tko）。Shift+M：删除最近的标记。
- F1 F2 F3 F4：切换模式。Ctrl+S：保存。Esc：离开（未保存时会询问）。
- ?：显示所有快捷键。
